完成最小可重用 ParaView snapshot 工具 `postprocess/paraview_snapshots.py`。它留在既有 postprocess CLI 邊界，不讓 `lib/` 依賴 ParaView，也沒有新增 class/framework。

使用者在 ParaView GUI 開啟任一代表性 PVD，完成 camera、projection、coloring、colormap、range、scalar bar/legend 後以 File > Save State 保存 `.pvsm`。Job 以 JSON（或 pvpython 有 PyYAML 時使用 YAML）提供 state、multiple PVD sources、physical times、output directory、resolution，以及可選的 coloring/color_range。工具解析所有 PVD timestep，將 requested physical times 全域排序與去重，再重指定同一個 state reader 的 FileName，逐幀以同一 view/display/LUT 輸出 PNG；既有目標 PNG 不覆寫。

ParaView 6.1.1 smoke test 使用 ADR01 的 0-420 s 與 420-1800 s 兩個 PVD，輸入未排序且重複的 `[1800, 420, 430, 420, 0]`，成功產生依序為 0、420、430、1800 s 的四張 320x240 PNG，420 s 僅一張，temperature range 固定 1-4 K。臨時 state/config/PNG 已清除；simulation output 未修改。
