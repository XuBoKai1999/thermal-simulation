# Workflow cadence fixes and S2 validation

## Workflow fixes

- Added independent `--summary-every` cadence. It defaults to every solver step
  and stores scalar observations, per-step/cumulative Newton iterations, and P1
  checkpoints without writing full dump/VTK output.
- `--output-every` now controls only heavy dump/VTK frames.
- Audit curvature now uses differences of signed sample-temperature slopes,
  representing absolute second-difference curvature rather than change in slope
  magnitude.
- Random audit selection now uses only indices `1..n-2`, excluding both segment
  endpoints.
- GGG temperature is reported with `gate=informational`, `pass=null`; it no longer
  appears to pass an unstated acceptance criterion and is excluded from the final
  gate calculation.

No physics, geometry, material, IC, BC, contact model, or solver formulation was
changed.
