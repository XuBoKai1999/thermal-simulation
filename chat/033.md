# ADR01 continuous-trajectory workflow implementation

Implemented the plan-driven ADR01 workflow without changing Baseline v1 physics
or checkpoint format. Initial state was branch `main`, commit `1eb6848`, with a
clean working tree.

Changed `lib/dump.py`, `run/01_ADR01/main.py`, `workflow.py`, ADR01 architecture,
roadmap, workflow and output documentation, plus root `arch.md`, `handoff.md`, and
`dump-format.md`. Added only `run/01_ADR01/baseline-v1.yaml` as required user
input (and this mandatory chat archive entry).

The new CLI is:

```powershell
.\scripts\wsl-run.ps1 "python3 run/01_ADR01/workflow.py run run/01_ADR01/baseline-v1.yaml"
```

It validates the full plan before FEM setup, executes production plus same-start
`dt/2` branches, supports warn/strict, propagates accumulated validity, avoids
near-zero relative-flow division, reports threshold crossings informationally,
and creates one production summary/manifest/log/PVD with physical-time dumps and
checkpoints. Reference data stays below `validation/`.

Tests passed: WSL syntax compilation, workflow self-test (plan validation,
near-zero classification, crossing interpolation, audit selection, validity
propagation), generic 3D dump/read regression, a real 1.5 ms two-segment run at
two production timesteps in warn mode, and a real strict-stop run. The short run
had continuous times 0, 0.00025, 0.0005, 0.001, 0.0015 s with no duplicated
boundary row; both intentionally coarse local comparisons failed, warn continued,
and strict stopped after its first failure. Temporary generated test output was
removed after inspection. The prior verified split/restart equivalence and exact
P1 checkpoint format were preserved; the short run also restarted segment 2 from
the segment-1 endpoint successfully.

The full 0-420 s run was not launched. S3 and S4 remain unvalidated, checkpoints
remain serial-only, and an existing scenario directory is never overwritten.
Review the five plan intervals, provisional gates, expected runtime/storage, and
warn versus strict choice before production.
