# ADR01 steps2 Step 2 complete — self-describing dump metadata

## Work completed

- Advanced the dump writer to format v2 with explicit `TIMESTEP`, physical
  `TIME`, `SOLVER_DT`, `CHARACTERISTIC_CELL_SIZE`, `MESH_ID`, and LAMMPS-like
  `BOX BOUNDS` metadata.
- Added mesh-derived global bounds and `characteristic_cell_size` to
  `analyze.analyze`.
- Defined the generic characteristic size as the all-cell median of
  `cell_measure^(1/topological_dimension)`; for 3D tetrahedra this is median
  `V_K^(1/3)` and is explicitly not a global `dx`.
- Kept `write_dump` backward-conscious by appending optional arguments. Unknown
  dt/size values serialize as `unknown`.
- Kept reader compatibility with format-v1 `BOUNDS`; both old `BOUNDS` and new
  `BOX BOUNDS` are accepted and exposed as aliases.
- Updated every existing repository dump call to supply characteristic size and,
  for transient runs, solver dt.
- Extended Test 07 with v2 metadata checks and a legacy-v1 reader fixture.
- Marked `steps2.md` Step 2 complete. No separate `mesh-info.json` was added.
