# Shared runtime logging capability

Added the single approved shared entity, `lib/log.py`. Its thin `RunLog` defaults
to terminal output every 10 solver timesteps with no file. It timestamps every
message, always emits first/final progress, supports unconditional events, and
optionally writes the identical stream by append with immediate flush. There are
no handlers, formatter hierarchy, background thread, or command parser.

ADR01 `main.py` now accepts a logger, label, progress cadence, optional log path,
and terminal switch, and calls `progress()` after every completed solver step.
Its solver, checkpoint, dump, and summary logic is otherwise unchanged. Direct
CLI options are `--progress-every`, `--log`, and `--no-terminal`.

ADR01 `workflow.py` creates one logger at `output/<scenario>/run.log`, passes it
to production/reference branches, and emits simulation/branch START and DONE,
validation PASS/WARNING, and safe branch ERROR events. `validation.log` remains
separate. The manifest now includes `total_wall_time_s`, `started_at`, and
`finished_at`; branch `wall_time_s` remains unchanged.

Regressions passed in WSL2: syntax compilation, `lib/log.py` self-test, existing
workflow self-test, and a 1.25 ms two-segment strict workflow with cadence 2.
The live `run.log` was readable before process completion, confirming incremental
append/flush. S0 production printed step 1/1; S1 production printed steps 1/2 and
2/2; S1 reference printed steps 1/4, 2/4, and 4/4 (not 3/4), with correct labels,
physical times, dt, Newton counts, and wall values. Strict validation still
stopped after failure, summary times remained de-duplicated, physical-time dump
and checkpoint outputs were produced, and the manifest recorded total wall time
38.27 s plus timestamps. Temporary regression input/output was removed. The
previously completed 420-second simulation was not rerun.
