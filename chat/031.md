# ADR01 segmented workflow infrastructure and S1 validation

## Completed infrastructure

- Continuation directories now encode run type, absolute start/end, and dt:
  `segment|validation|audit_t_<start>_to_<end>_dt_<dt>`.
- The legacy from-zero `dt_<dt>` directory remains unchanged.
- Every full-field output time writes a restartable P1 checkpoint; every run
  always retains its endpoint checkpoint.
- Solver dt and full dump/VTK output cadence remain independent.
- ADR01 automatically rejects non-finite output data and temperatures outside
  the current Baseline v1 `[1,4] K` expectation.
- Added case-local `workflow.py` with:
  - common-time dt/dt/2 comparison;
  - endpoint full-P1 max and L2 error;
  - GGG/cold-stage/sample averages and three heat-flow errors;
  - provisional convergence gates with stable flow normalization;
  - linearly interpolated 1.5/2/3 K sample failure times;
  - reproducible stratified/targeted/random audit-point selection.
- Comparison output includes CSV, JSON, plot, and Markdown report.

## S1 numerical test

Both branches started from the same canonical
`output/dt_0.00025/checkpoint_t_0.05.npz` and ended at `t=0.5 s`, with common
outputs every 0.05 s.

- Candidate `dt=0.025 s`: 18 steps, 57 Newton iterations, 35.64 s wall time.
- Reference `dt=0.0125 s`: 36 steps, 110 Newton iterations, 38.05 s wall time.
- Both runs converged, stayed finite, and remained in `[1,4] K`.

| support 1 flow | 0.5716 uW | 0.8257% |

| switch flow | 0.1473 uW | 0.0811% |

Endpoint full-P1 difference: maximum `0.0042991 K`, L2 `0.0373839 K` over
2506 DOFs. No requested failure threshold was crossed in S1.

S1 passes all provisional gates. The accepted production endpoint is:

`run/01_ADR01/output/segment_t_0.05_to_0.5_dt_0.025/checkpoint_t_0.5.npz`
