# ADR01 heat-switch documentation decision

ADR01 active documentation now distinguishes the frozen Baseline v1 conceptual ideal-open OFF
switch from the approved first solver implementation: a finite-leakage effective bulk proxy using
the existing thin `heat_switch` volume.

The geometry source gives `L = 0.0005 m`; both switch interfaces have generated shared area
`A_effective = 1.9634954084936207e-5 m²`. With the approved literature-scale target
`G_off = 6.0e-5 W/K`, `k = G L / A` gives `k_off = 1.5278874536821952e-3 W/(m K)`.
This is a numerical proxy, not an ADR01 hardware value. It has finite leakage. The ON state and
switching logic are not modeled.

Updated: ADR01 `arch.md`, `steps.md`, `AGENTS.md`, parameter README and material map, geometry
report/README wording, plus root `steps.md` and `handoff.md`. Baseline v1, papers, geometry data/code,
mesh, other materials, BC/IC, and physics remain untouched. No conflicting active heat-switch
statement remains; ideal-open references survive only as clearly labeled conceptual Baseline v1.
