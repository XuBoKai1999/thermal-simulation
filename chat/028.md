# ADR01 restart/continuation support

## Completed

- Extended the existing ADR01 runner with a minimal serial checkpoint path.
- Every completed run writes `checkpoint_final.npz` containing format version,
  mesh identity, absolute time, and the exact continuous P1 temperature vector.
- Added `--restart <checkpoint>`; `--end` remains an absolute simulation time.
- Continuations derive their output schedule from elapsed continuation time, so
  a checkpoint at `0.05 s` with `dt=output_every=0.1 s` writes `0.05`, `0.15`,
  `0.25`, ... rather than restarting the physical clock at zero.
- Continuation output uses `dt_<dt>_from_<start-time>` and therefore does not
  overwrite the corresponding from-zero run.
- Loading rejects unsupported format versions, wrong mesh IDs, incompatible
  vector shapes, non-finite fields, and invalid checkpoint times.

## Files changed

- `run/01_ADR01/main.py` — checkpoint save/load, restart CLI, absolute-time
