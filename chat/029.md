# ADR01 split-run equivalence verification

## Scope

Verified that checkpoint continuation preserves the subsequent numerical
trajectory, not only the loaded initial state. No code or physics was changed.

## Runs

- Split continuation: loaded the validated `t=0.05 s` checkpoint and ran
  `0.05→0.10 s` with `dt=0.00025 s`; 200 steps, 939 Newton iterations, PASS.
- Continuous reference: ran `0→0.10 s` with `dt=0.00025 s`; 400 steps,
  1982 Newton iterations, PASS.

Both used output every `0.05 s`. Split output is isolated under
`output/dt_0.00025_from_0.05/`; continuous output is under
`output/dt_0.00025/`.

## Equivalence at t=0.10 s

- P1 vector size: 2506 DOFs.
- `numpy.array_equal(continuous, split)`: `True`.
- Maximum absolute P1-vector difference: `0`.
- P1-vector L2 difference: `0`.
- Maximum difference across GGG/cold-stage/sample average temperatures and
  support-1/support-2/switch heat flows: `0`.
- The six-metric arrays are also bitwise identical.

This proves save/load fidelity and continuation trajectory fidelity for the
current frozen, serial ADR01 case and mesh.
