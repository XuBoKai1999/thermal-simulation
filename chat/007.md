# ADR01 幾何工作啟動檢查

目前不能開始建立 3D 幾何。`run/01_ADR01/steps.md` 的 Step 0 仍標示為
`STATUS: INCOMPLETE`，而 `run/01_ADR01/AGENTS.md` 明定這是人工設計閘門；在人工將其改為
`STATUS: COMPLETE` 前，Codex 只能回報未定決策，不能進入實作。

尚待人工確認並凍結的項目是：

- baseline PDE 與簡化條件；
- 10 個實體 component inventory，以及 hot/cold reservoir 是否為求解實體；
- `draft-geometry.yaml` 所示最小 geometry contract（mm、座標、cylinder/box、定位與語意表面）；
- `connections.yaml` 的 11 個穩定 edge ID 與 geometry edge 到 thermal interface 的對應；
- 物性與介面參數的 provenance schema；
- 互動式 3D 檢視的最低輸出與人工核准程序。

現有幾何需求本身已足以作為 placeholder 草模輸入，且明確要求所有數字不得宣稱為工程尺寸。
請人工審核 Step 0 後，把狀態改成 `STATUS: COMPLETE`；之後即可依現有 Gmsh 工作流建立
`requirement -> 3D geometry -> interactive inspection`，驗證全部 component ID、edge ID、接觸、
間隙與重疊，但不進行熱求解。
