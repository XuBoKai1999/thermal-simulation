# ADR01 solver properties and validation

Solver-facing Baseline v1 properties are implemented in `run/01_ADR01/case.yaml`,
`properties.py`, `ggg_k.csv`, and `ggg_cp.csv`. Cu RRR100/RRR50 and G-10 k use
canonical analytical callables; GGG H=0 k/cp use piecewise-linear tables; G-10 cp
uses the complete saved NIST regenerator series through the existing table loader
with an optional scale and explicit 1–4 K domain. No property silently extrapolates.

Generic additions are minimal: `time.initial_condition.type: by_region` with
`default_K` plus semantic region overrides, and optional table `scale`/`domain_K`.
Unknown IC regions and non-finite temperatures fail during case loading. Existing
uniform/split-x behavior remains.

Property validation passes. Max absolute checkpoint errors: Cu RRR100 k
0.00462511 W/(m K), Cu cp 1.97964e-7 J/(kg K), Cu RRR50 k 0.00363656 W/(m K),
G-10 k 1.72563e-7 W/(m K). GGG table points reproduce exactly; G-10 volumetric
reconstruction error is 5.68434e-14 J/(m3 K). Switch G error is 6.78e-21 W/K:
G=6e-5 W/K, R=16666.6667 K/W, Q(1 K)=60 uW, Q(3 K)=180 uW. Its placeholder
C is 9.81747704e-9 J/K, 4.22858e-5 of the smaller adjacent Cu capacitance (<0.1%).

`material-map.yaml` now marks the finite-leakage proxy implemented. Exact next
